ReproCapsule

Turn a browser failure into a privacy-safe, portable reproduction artifact.

1. Capture an intentionally broken checkout

Enter any email and password. The demo records interactions locally, then triggers a genuine local 500 API response and console error.

2. Privacy boundary

Exported output masks password fields, secret-like query parameters, and sensitive request headers before a file is created.

3. Inspect exactly what leaves the browser

Capture a failure to inspect its sanitized events.

4. Create and verify the capsule

Save the downloaded JSON, then run:

npm run build
node dist/src/cli.js export path/to/capture.json artifacts/checkout.capsule
node dist/src/cli.js verify artifacts/checkout.capsule

The generated replay.spec.ts is real Playwright test source. Its execution is intentionally separate and requires installing Playwright in the target project.
