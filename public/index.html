ReproCapsule

Turn a browser failure into a privacy-safe, portable reproduction artifact.

1. Capture an intentionally broken checkout

Enter any email and password. The demo records the relevant actions locally, then triggers a genuine local 500 API response and console error. Stable demo selectors are labelled high confidence; every generated replay asks for review.

2. Privacy boundary

Secrets are sanitized before they reach the preview or downloaded file. Request/response bodies, cookies, and telemetry are never captured.

3. Inspect what leaves the browser

Capture a failure to inspect its sanitized events.

4. Inspect another capture locally

Select a JSON event export. The file stays in this browser; unknown fields, bodies, and cookies are rejected before display.

Imported sanitized evidence

No local capture imported.

5. Create and verify the capsule

Save the downloaded JSON, then run:

npm run build
node dist/src/cli.js export path/to/capture.json artifacts/checkout.capsule
node dist/src/cli.js verify artifacts/checkout.capsule

The exported capsule includes a self-contained HTML report and generated Playwright source. Browser replay is executed only when the documented Playwright command runs in a target project.
